## 冠心病概述

### 什么是冠心病
冠心病（冠状动脉粥样硬化性心脏病）是指冠状动脉发生粥样硬化，管腔狭窄或阻塞，导致心肌缺血、缺氧、坏死的一类心脏病。可分为稳定性心绞痛、急性冠脉综合征（不稳定心绞痛、心肌梗死）等类型。

### 危险因素（可控与不可控）
| 分类 | 危险因素 |
|------|---------|
| 不可控 | 年龄（男性≥45、女性≥55）、遗传家族史 |
| 可控 | 高血压、高血脂、糖尿病、吸烟、肥胖、缺乏运动、长期精神紧张 |

## 典型症状与识别

### 心绞痛典型表现
1. 胸骨后压榨样、紧缩感疼痛，可向左臂、颈部、下颌放射
2. 多在劳累、情绪激动、饱餐后诱发
3. 持续数分钟（通常3-5分钟），休息或含服硝酸甘油可缓解

### 与心梗的鉴别（重要）
1. 心梗疼痛更剧烈，持续>20分钟，休息/含服硝酸甘油不缓解
2. 伴大汗、恶心呕吐、濒死感
3. 不典型人群（老年人、女性、糖尿病患者）可仅表现为气短、乏力、上腹不适、牙痛

### 需要立即就医的危险信号
1. 胸痛持续>15分钟不缓解
2. 含服硝酸甘油无改善
3. 伴大汗淋漓、面色苍白、濒死感
4. 晕厥、血压下降、脉搏细弱

## 家庭生活方式管理

### 饮食管理
1. 低盐（<5g/日）、低脂、低糖饮食
2. 减少饱和脂肪和反式脂肪摄入，少食动物内脏、油炸食品
3. 多吃全谷、蔬果、鱼类（富含Omega-3）、豆制品
4. 控制总热量，维持健康体重

### 运动管理
1. 病情稳定者每周150分钟中等强度有氧运动（快走、游泳）
2. 用"谈话测试"控制强度：运动时能正常交谈但无法唱歌为宜
3. 有造影或出现症状加重时暂停运动，先就医
4. 避免清晨剧烈运动、餐后立即运动、严寒酷热下锻炼

### 戒烟限酒
1. 吸烟是冠心病最重要的可控危险因素，必须彻底戒烟
2. 严格限酒或戒酒

## 药物治疗

### 常用冠心病药物分类
| 药物类别 | 代表药 | 作用/注意事项 |
|---------|--------|------------|
| 抗血小板药 | 阿司匹林、氯吡格雷 | 防血栓，需长期服用，注意出血风险 |
| 降脂药（他汀类） | 阿托伐他汀、瑞舒伐他汀 | 稳斑块、降胆固醇，注意肝功能/肌痛 |
| β受体阻滞剂 | 美托洛尔、比索洛尔 | 减慢心率、减少心肌耗氧 |
| 硝酸酯类 | 硝酸甘油（急救含服） | 扩张冠状动脉，缓解心绞痛 |
| ACEI/ARB | 依那普利、缬沙坦 | 保护心脏，降压 |
| 钙通道阻滞剂 | 氨氯地平、地尔硫卓 | 扩血管，防冠脉痉挛 |

### 硝酸甘油急救使用要点
1. 出现胸痛时立即舌下含服1片（0.5mg）
2. 平卧位含服（避免直立性低血压）
3. 若5分钟不缓解可再含1片，最多3片
4. 含服2次仍不缓解，立即拨打急救电话（高度怀疑心梗）

### 用药原则
1. 所有抗栓、降脂药物需长期规律服用，不可擅自停药
2. 出现牙龈/皮肤出血、黑便、异常瘀斑及时告知医生
3. 勿自行增减剂量，用药调整须遵医嘱

## 并发症与危险信号（及时就医）
1. 急性心肌梗死：持续胸痛、大汗、濒死感
2. 心力衰竭：呼吸困难、夜间憋醒、下肢水肿
3. 心律失常：心悸、晕厥、脉搏不规律
4. 支架/搭桥术后再发胸痛、发热、伤口异常

### 需立即就医的紧急情况
1. 持续胸痛>15分钟含硝酸甘油不缓解
2. 突发严重呼吸困难、端坐呼吸
3. 晕厥、意识不清
4. 心悸伴明显头晕、脉搏极慢或极快

## 就医与随访
1. 稳定期冠心病建议每3-6个月门诊复查
2. 定期查血脂、肝肾功能、心电图、心脏超声
3. 支架植入者服用双抗（阿司匹林+氯吡格雷）期间遵医嘱
4. 控制血压、血糖、血脂三达标
