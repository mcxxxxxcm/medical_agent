## 血糖血脂概述

### 什么是血糖血脂检查
评估糖代谢（血糖、糖化血红蛋白）与脂代谢（胆固醇、甘油三酯）状况，是糖尿病、心血管风险评估的核心。**不同人群（尤其糖尿病/心血管病者）控制目标更严格。**

## 血糖指标解读

| 指标 | 参考/诊断标准 |
|------|-------------|
| 空腹血糖 | 正常<6.1；糖尿病前期6.1-6.9；糖尿病≥7.0 mmol/L |
| 餐后2小时血糖 | 正常<7.8；糖尿病前期7.8-11.0；糖尿病≥11.1 mmol/L |
| 糖化血红蛋白(HbA1c) | 正常<5.7%；糖尿病前期5.7-6.4%；糖尿病≥6.5% |
| 随机血糖 | ≥11.1 mmol/L 伴症状提示糖尿病 |

### 血糖解读要点
1. 单次空腹轻度升高（6.1-6.9）提示糖尿病前期，是干预窗口期
2. **HbA1c反映近2-3个月平均血糖**，比单次血糖更稳定，是随访核心指标
3. 糖尿病控制目标：一般成人空腹4.4-7.0、餐后<10.0、HbA1c<7.0%（个体化，遵医嘱）
4. 糖化血红蛋白受贫血、近期失血/输血、溶血影响，须结合临床
5. 妊娠、高龄、合并心肾疾病者目标不同，以医生方案为准

## 血脂指标解读

| 指标 | 一般参考 | 意义 |
|------|---------|------|
| 总胆固醇(TC) | <5.2 mmol/L | 血脂总体水平 |
| 甘油三酯(TG) | <1.7 mmol/L | 与饮食、饮酒相关 |
| LDL-C(低密度) | <3.4 mmol/L | "坏胆固醇"，动脉硬化主因 |
| HDL-C(高密度) | ≥1.0 mmol/L | "好胆固醇"，保护血管 |

### 血脂解读要点（重点：危险分层）
1. **LDL-C是核心指标**，但不同风险者目标不同
2. 已确诊冠心病、糖尿病、脑卒中、外周动脉病者为"极高危"，LDL-C目标常<1.8甚至<1.4mmol/L
3. 仅一个"正常范围"未必达标——须按个人危险因素分层
4. 甘油三酯明显升高（>5.6）警惕急性胰腺炎，需及时就医
5. 血脂受饮食、肥胖、绝经、甲状腺功能、糖尿病等影响

## 报告组合看单要点
1. 空腹血糖+HbA1c + 血脂（TC/LDL/TG/HDL）整体评估代谢风险
2. 血压+血糖+血脂常同步升高（代谢综合征），互相促进
3. 糖尿病者应关注LDL-C达标，而不只"血糖正常就放心"
4. 血脂长期不达标，即使无不适，心脑血管风险显著升高

## 正确检测注意事项
1. 血糖：空腹8小时以上采血；随机血糖随时可测
2. 血脂：空腹（多数建议空腹8-12小时）前避免高脂餐、饮酒
3. 急性感染、心肌梗死后早期血糖/血脂可一过性升高
4. 单次异常勿惊慌，可复查；持续异常才有诊断意义

## 需及时就医的信号
1. 空腹血糖≥7.0或餐后≥11.1（直接诊断为糖尿病）
2. HbA1c明显升高，或伴多饮多尿多食消瘦
3. 已患糖尿病/心血管病但血脂LDL未达标
4. 甘油三酯>5.6 mmol/L（胰腺炎风险，伴腹痛立即就医）
5. 出现视物模糊、伤口不愈、反复感染、泡沫尿

## 随访建议
1. 糖尿病前期：生活方式干预，3-6个月复查
2. 糖尿病患者：每3-6个月复查HbA1c、血脂，并按需监测血糖
3. 服用降脂药者定期复查血脂、肝功能、肌酶
4. 达标稳定者遵医嘱延长复查间隔
