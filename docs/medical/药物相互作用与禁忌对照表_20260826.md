## 药物相互作用概述

### 什么是药物相互作用
药物相互作用指同时或先后服用多种药物时，某种药改变另一种药在体内的吸收、代谢、效果或毒性。高血压、糖尿病、心脏病等慢病患者常需长期服用多种药物，是相互作用高发人群。

### 为什么需警惕
1. 可降低药效 → 疾病控制不佳
2. 可增加毒性 → 肝肾功能损伤、出血等严重后果
3. 中老年渐多病种、多药共存，叠加风险更高

## 重点药物相互作用对照

| 组合 | 后果 | 应对 |
|------|------|------|
| 阿司匹林+其他抗凝药（华法林） | 出血风险明显增加 | 定期查凝血功能，医生指导下联用 |
| 他汀类+贝特类降脂药 | 肌损伤、横纹肌溶解风险增加 | 需医生评估，避免自行联用 |
| 布洛芬+阿司匹林 | 增加胃肠出血、削弱阿司匹林心脏保护 | 换药或错开，遵医嘱 |
| 头孢类/甲硝唑+酒精 | 双硫仑样反应，可致命 | 服药前后1周忌酒 |
| 多种含对乙酰氨基酚的复方感冒药合用 | 对乙酰氨基酚过量伤肝 | 服药前核对成分表 |
| 钙拮抗剂+西柚(葡萄柚) | 血药浓度升高致低血压 | 服此类药避免吃西柚 |
| 华法林+大量绿叶蔬菜(维生素K) | 药效波动 | 保持维生素K摄入稳定 |
| 降压药+多种感冒药(含伪麻黄碱) | 血压升高 | 感冒期间监测血压，遵医嘱 |

## 常见药物禁忌（绝对/相对）
| 药物 | 禁忌/慎用人群 |
|------|-------------|
| 青霉素类 | 青霉素过敏者禁用 |
| 喹诺酮类 | 18岁以下、孕妇哺乳期慎用 |
| ACEI降压药 | 妊娠、严重肾功能不全慎用 |
| 布洛芬等NSAID | 胃溃疡、消化道出血史、重度肾功能不全慎用 |
| 他汀类 | 活动性肝病、明显肝功能异常禁用 |
| 二甲双胍 | 重度肾功能不全、缺氧状态（急性心梗）慎用 |

## 安全用药排查清单（就医/开药前）

### 就诊时应主动告知医生
1. 全部正在服用的药（含处方药）、保健品、中成药、草药
2. 有无食物/药物过敏史
3. 有无肝肾功能不全、肝肾疾病史
4. 是否怀孕、哺乳或计划妊娠

### 自行购买非处方药时
1. 核对成分表，避免与在服药成分重复
2. 感冒、止痛、胃肠药最易与慢病用药冲突
3. 拿不准时先咨询药师

## 老年人多药共用的注意事项
1. 建立"用药清单"，记录药名、剂量、时间，复诊时一并出示
2. 避免重复同类药、作用机制重叠
3. 定期（每3-6个月）请医生复核用药，删减不必要药物
4. 更换任何新药后密切观察，出现乏力、头晕、嗜睡及时反馈
5. 勿自行加药、减药或停用长期药

## 需立即就医的信号
用药出现以下情况及时就医：
1. 不明原因出血（牙龈、皮肤瘀斑、黑便）
2. 严重低血压、晕厥
3. 明显乏力、肌肉酸痛伴深色尿
4. 皮肤过敏、黄疸、尿量显著减少
5. 心慌、心悸、意识改变
