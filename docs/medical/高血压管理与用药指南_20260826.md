## 高血压概述

### 什么是高血压
高血压是指体循环动脉血压持续高于正常水平的一种慢性疾病。正常成人血压应低于 **140/90mmHg**，长期血压升高会损害心、脑、肾等重要器官。

### 血压分级
| 分类 | 收缩压(SBP) | 舒张压(DBP) |
|------|------------|------------|
| 正常血压 | <120 | <80 |
| 正常高值 | 120-139 | 80-89 |
| 1级高血压 | 140-159 | 90-99 |
| 2级高血压 | 160-179 | 100-109 |
| 3级高血压 | ≥180 | ≥110 |

### 发病原因
1. 原发性高血压：占绝大多数，与遗传、高盐饮食、肥胖、缺乏运动、精神紧张有关
2. 继发性高血压：由肾病、内分泌疾病（嗜铬细胞瘤、原发性醛固酮增多症）、药物等引起
3. 老年性高血压：以单纯收缩压升高为特点

## 高血压常见症状

大多数高血压起病隐匿，多数患者无明显症状，仅在测量时发现。可能出现的表现：
1. 头晕、头痛，多为后枕部胀痛
2. 颈项板紧感
3. 心悸、胸闷、乏力
4. 视物模糊
5. 鼻出血（血压显著升高时）

### 高血压危象与危险信号（需立即就医）
1. 收缩压≥180或舒张压≥110，伴剧烈头痛
2. 胸痛、胸闷，意识模糊或昏倒
3. 单侧肢体无力、言语不清（警惕中风）
4. 剧烈头痛伴呕吐、视物障碍（警惕脑出血）
5. 呼吸困难、下肢水肿（警惕心衰）

## 家庭血压管理

### 正确的家庭测量方法
1. 安静休息5分钟后测量
2. 采用上臂式电子血压计，袖带与心脏同高
3. 每天早、晚各测1次，每次测2遍取平均
4. 记录血压日记，就诊时供医生参考

### 生活方式干预
| 措施 | 要求 |
|------|------|
| 限盐 | 每日食盐<5g（约一啤酒瓶盖），减少腌制/加工食品 |
| 控体重 | BMI控制在18.5-24，腰围男性<90cm、女性<85cm |
| 规律运动 | 每周至少150分钟中等强度有氧运动（快走、游泳、骑车） |
| 限酒 | 男性每日≤25g酒精，建议不饮酒 |
| 戒烟 | 吸烟会升高血压并损伤血管 |
| 减压 | 保证睡眠，减少焦虑，练习深呼吸/冥想 |
| 膳食 | DASH饮食：多吃蔬果、全谷、低脂奶，少红肉 |

## 药物治疗

### 常用降压药分类
| 药物类别 | 代表药 | 常见副作用/注意事项 |
|---------|--------|-------------------|
| 钙通道阻滞剂(CCB) | 氨氯地平、硝苯地平 | 脚踝水肿、面部潮红、头痛 |
| 血管紧张素转化酶抑制剂(ACEI) | 依那普利、贝那普利 | 干咳、升钾，妊娠禁用 |
| 血管紧张素Ⅱ受体拮抗剂(ARB) | 缬沙坦、厄贝沙坦 | 升钾，妊娠禁用 |
| 利尿剂 | 氢氯噻嗪 | 低钾、尿酸升高、多尿 |
| β受体阻滞剂 | 美托洛尔、比索洛尔 | 心率减慢，哮喘/慢阻肺慎用 |

### 用药原则
1. 降压药需长期坚持，不可自行停药或减量
2. 主张长效制剂，每日1次，平稳降压
3. 首选单药，效果不达标时联合用药
4. 从低剂量开始，缓慢调整，避免血压骤降
5. 春季/冬季或季节变化时注意复查调药
6. 任何用药调整都应在医生指导下进行

### 常见误区
1. 血压正常就停药 → 血压反弹更危险
2. 凭感觉服药 × 血压高时才有症状
3. 保健品代替降压药 × 不能替代正规治疗
4. 血压降得越快越好 × 骤降可致脑供血不足

## 高血压并发症
1. 心脏：冠心病、心肌梗死、心力衰竭
2. 脑：脑卒中（出血性/缺血性）
3. 肾：肾功能减退、蛋白尿
4. 眼：视网膜病变、视力下降
5. 血管：主动脉夹层（极危险）

## 就医与随访建议
1. 初诊或调药期：每月随访1次
2. 血压稳定后：每3-6个月复查一次
3. 每年体检：查血糖、血脂、血肌酐、尿微量白蛋白、眼底
4. 居家血压记录供医生评估疗效
