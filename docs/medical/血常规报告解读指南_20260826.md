## 血常规概述

### 什么是血常规
血常规反映血细胞数量与形态，是最基础、最常用的检查，用于筛查贫血、感染、血液系统疾病，辅助评估多种疾病。**单项异常不等于有病，须结合临床综合判断。**

### 三系细胞
1. 红系：红细胞（RBC）、血红蛋白（Hb）— 携氧
2. 白细胞系：白细胞总数（WBC）及分类 — 免疫防御
3. 血小板系：血小板（PLT）— 止血凝血

## 常见指标参考范围

| 指标 | 成人参考范围（单位） | 主要意义 |
|------|---------------------|---------|
| 红细胞(RBC) | 男4.3-5.8、女3.8-5.1 ×10^12/L | 携氧能力 |
| 血红蛋白(Hb) | 男130-175、女115-150 g/L | 判断贫血最主要指标 |
| 红细胞压积(HCT) | 40%-50%(男)/37%-48%(女) | 血液黏稠度 |
| 白细胞(WBC) | 3.5-9.5 ×10^9/L | 感染、炎症 |
| 中性粒细胞 | 40%-75% | 细菌感染时升高 |
| 淋巴细胞 | 20%-50% | 病毒感染时升高 |
| 血小板(PLT) | 125-350 ×10^9/L | 止血凝血 |

## 常见结果解读

### 贫血（血红蛋白↓）
1. 轻中重度划分：轻度Hb>90、中度60-90、重度<60g/L
2. 常见原因：缺铁、失血、缺乏B12/叶酸、慢性病、造血异常
3. 明显贫血伴乏力、头晕、面色苍白应就医明确原因

### 白细胞变化
| 变化 | 常见情况 |
|------|---------|
| 白细胞/中性粒↑ | 细菌感染、炎症、应激 |
| 淋巴细胞↑ | 病毒感染（感冒、流腮） |
| 白细胞明显↓ | 病毒感染恢复期、药物影响、血液病（需警惕） |

### 血小板变化
1. 升高：感染反应、缺铁、真性红细胞增多（需排除）
2. 明显降低：免疫性减少、药物、肝病、血液病（出血风险，须就医）

## 血常规报告看单要点
1. 关注**显著偏离参考范围**的项目（尤其超出范围数倍）
2. 三系血细胞（WBC/Hb/PLT）**同时异常**更需重视，警惕血液系统问题
3. 化验结果受近期感染、药物、脱水、采血时间影响（如白细胞有昼夜变化）
4. 报告单仅供参考，**确诊须结合病史体征和进一步检查**

## 需及时就医的信号
1. 血红蛋白明显低（尤其<90g/L）伴乏力、心悸、黑便、便血
2. 血小板显著降低（<50 ×10^9/L）或伴皮肤瘀斑、牙龈出血
3. 白细胞显著/持续异常，伴发热、淋巴结肿大、消瘦
4. 不明原因的长期乏力、面色苍白、反复感染
5. 结果明显异常且本人无法解释，或医生明确建议复查

## 复查与随访
1. 轻度异常且无不适，可医生评估后择期复查
2. 治疗中（如补铁、抗感染）按医嘱定期复查评估疗效
3. 备孕、慢性贫血、出血倾向者遵专科随访
