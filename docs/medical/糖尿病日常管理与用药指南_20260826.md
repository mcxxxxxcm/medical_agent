## 糖尿病概述

### 什么是糖尿病
糖尿病是以血糖升高为特征的代谢性疾病，由于胰岛素分泌不足或作用障碍所致。长期高血糖会损害血管和神经，累及眼、肾、心、足部。

### 诊断标准
| 检测指标 | 糖尿病 | 糖尿病前期 |
|---------|-------|-----------|
| 空腹血糖 | ≥7.0mmol/L | 6.1-6.9 |
| 餐后2小时血糖 | ≥11.1mmol/L | 7.8-11.0 |
| 糖化血红蛋白(HbA1c) | ≥6.5% | 5.7-6.4 |

### 分型
1. 1型糖尿病：胰岛素绝对缺乏，多见于青少年，必须注射胰岛素
2. 2型糖尿病：最常见，多与肥胖、胰岛素抵抗相关，成人多见
3. 妊娠期糖尿病：孕期首次发现
4. 特殊类型：遗传、药物、胰腺疾病等

## 典型症状与识别

### 常见症状（三多一少）
1. 多饮、多尿、多食
2. 体重不明原因下降
3. 乏力、皮肤瘙痒、伤口不易愈合
4. 视力模糊、反复感染

### 高危人群筛查建议（即使无症状也需查血糖）
1. 年龄≥40岁
2. 肥胖（BMI≥28）
3. 有糖尿病家族史
4. 高血压、血脂异常
5. 妊娠期糖尿病史
6. 长期静坐、生活方式不健康

## 家庭血糖管理

### 自我监测
1. 血糖仪采指尖血，保持手指清洁
2. 监测频次：治疗初期/调药期每日多次，稳定后遵医嘱减少
3. 记录空腹、餐后血糖及用药、饮食、运动情况
4. 每3个月到医院测一次糖化血红蛋白（评估近2-3个月平均血糖）

### 控制目标（个体化，以医生为准）
| 指标 | 一般成人目标 |
|------|------------|
| 空腹血糖 | 4.4-7.0mmol/L |
| 餐后2小时血糖 | <10.0mmol/L |
| 糖化血红蛋白 | <7.0% |

## 生活方式管理

### 饮食管理
1. 主食定量，粗细搭配，控制总热量
2. 多食蔬菜（每日500g），适量水果（选低GI,两餐间）
3. 蛋白质：适量鱼、禽、蛋、豆制品
4. 限盐<5g/日，少油少糖
5. 规律进餐，定时定量，避免饥饿后暴食

### 运动管理
1. 每周150分钟中等强度有氧运动（快走、骑车、游泳）
2. 餐后1小时运动有助于降血糖
3. 力量训练（每周2次）改善胰岛素敏感性
4. 防低血糖：运动前可适当加餐，随身带糖
5. 足部有溃疡、神经病变者避免高强度运动

## 药物管理

### 常用口服降糖药
| 类别 | 代表药 | 作用/注意 |
|------|-------|----------|
| 二甲双胍 | 二甲双胍 | 一线首选，减少肝糖输出，可能胃肠道不适 |
| 磺脲类 | 格列美脲、格列齐特 | 促胰岛素分泌，注意低血糖风险 |
| DPP-4抑制剂 | 西格列汀 | 平稳降糖，体重影响小 |
| SGLT-2抑制剂 | 达格列净、恩格列净 | 排糖，有心肾保护，注意泌尿系感染 |
| GLP-1受体激动剂 | 司美格鲁肽 | 降糖兼减重，注意胃肠道反应 |
| α-糖苷酶抑制剂 | 阿卡波糖 | 延缓碳水吸收，餐时服用 |

### 胰岛素使用
1. 遵医嘱设定注射方案，勿自行增减剂量
2. 注射部位轮流更换：腹部、大腿、上臂
3. 冷藏保存（2-8℃），避免冷冻和阳光直射
4. 注意按时进餐，防低血糖

### 重点：什么时候警惕低血糖（需立即处理）
低血糖表现：心慌、出汗、手抖、饥饿、头晕、意识模糊。
处理：立即进食15g含糖食物（如2-3块方糖、半杯果汁），15分钟复测。仍低则再进食。

## 糖尿病并发症与危险信号（及时就医）
1. 足部：伤口红肿、发热、颜色发暗、足背动脉搏动弱 — 警惕糖尿病足
2. 眼：突发视物模糊、眼前黑影 — 警惕视网膜病变
3. 心：胸痛、气短 — 糖尿病易合并冠心病，心梗症状可不典型
4. 肾：泡沫尿、水肿 — 警惕肾病
5. 感染：反复泌尿系/皮肤感染、伤口不愈

### 血糖危急值（立即就医）
1. 血糖测不出或极高（>16.7mmol/L）伴恶心呕吐（警惕酮症酸中毒）
2. 反复低血糖（<3.9）伴意识改变
3. 出现胸痛、单侧无力、言语不清等急症

## 就医与随访
1. 稳定期每3-6个月复查糖化血红蛋白、血脂、肾功能
2. 每年做眼底、尿微量白蛋白、足部检查
3. 妊娠期或计划妊娠者需专科管理
