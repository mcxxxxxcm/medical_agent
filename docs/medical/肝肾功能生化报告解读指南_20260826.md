## 肝肾生化概述

### 什么是肝肾功能检查
通过检测血液中酶类、代谢产物，评估肝脏合成与解毒功能、肾脏滤过与排泄功能。是体检和慢病随访的常规项目。**结果需结合临床和影像，不能孤立判断。**

## 肝功能常见指标参考与意义

| 指标 | 成人参考范围 | 意义 |
|------|-------------|------|
| 丙氨酸转氨酶(ALT) | <40 U/L | 反映肝细胞损伤，最敏感 |
| 天冬氨酸转氨酶(AST) | <40 U/L | 肝、心肌、肌肉损伤均可能升高 |
| γ-谷氨酰转肽酶(GGT) | 男<60、女<45 U/L | 胆道/酒精性肝病 |
| 碱性磷酸酶(ALP) | 45-125 U/L | 胆道阻塞、骨病 |
| 总胆红素(TBIL) | <21 μmol/L | 黄疸评估 |
| 直接胆红素(DBIL) | <6.8 μmol/L | 阻塞性黄疸 |
| 总蛋白/白蛋白(ALB) | 65-85/40-55 g/L | 肝脏合成功能、营养 |

### 肝功能解读要点
1. 转氨酶轻度升高很常见（脂肪肝、饮酒、劳累、感染、药物）
2. 明显/持续升高伴乏力、黄疸须就医排除肝炎
3. GGT升高常与饮酒、脂肪肝、胆道疾病相关
4. 胆红素升高伴皮肤巩膜黄染（黄疸）须查清原因

## 肾功能常见指标参考与意义

| 指标 | 成人参考范围 | 意义 |
|------|-------------|------|
| 肌酐(SCr) | 男57-111、女41-73 μmol/L | 反映肾小球滤过，是核心指标 |
| 尿素氮(BUN) | 3.1-8.0 mmol/L | 肾功能、蛋白摄入影响较大 |
| 估算肾小球滤过率(eGFR) | ≥90 ml/min | 分期肾功能，越低越差 |
| 尿酸(UA) | 男208-428、女155-357 μmol/L | 降酸代谢，痛风 |

### 肾功能解读要点
1. 肌酐受肌肉量影响（肌肉多者偏高），且早期肾损可正常
2. **eGFR是评估分期关键**：eGFR<60持续3个月以上提示慢性肾病
3. 尿素氮受饮食蛋白、脱水影响，单独尿素氮升高意义有限
4. 尿酸升高与痛风、肾病、饮酒、高嘌呤饮食相关

## 肝肾功能报告中需重视的组合
1. 转氨酶+胆红素同时升高：警惕肝实质损害/黄疸
2. 蛋白尿+血肌酐升高：警惕肾病进展
3. 肌酐+尿素氮同时升高：提示肾功能严重受损（需就医）
4. 白蛋白降低+水肿：警惕肾病综合征、肝病、营养不良

## 相关影响因素（正确看待结果）
1. 转氨酶受饮酒、熬夜、剧烈运动、药物（他汀类、部分中药）影响
2. 采血需空腹（前一晚清淡饮食、避免饮酒）
3. 剧烈运动、大量肉食可使肌酐/尿素氮一过性升高
4. 单次轻度异常可复查，持续或波动异常才更有意义

## 需及时就医的信号
1. 肌酐明显/持续升高，或eGFR下降
2. 黄疸（皮肤巩膜发黄）+腹痛/发热
3. 水肿、少尿、蛋白尿
4. 转氨酶显著升高（数倍于上限）伴症状
5. 长期服用药物（降压、他汀、降糖、止痛药）者出现异常升动

## 复查与随访
1. 药物性肝损风险者定期复查肝功能与肌酶
2. 慢性肾病、乙肝/脂肪肝者遵医嘱定期监测eGFR、蛋白尿
3. 高尿酸者节制高嘌呤饮食、控制体重，必要时专科干预
