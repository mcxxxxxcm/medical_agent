## 尿常规概述

### 什么是尿常规
尿常规评估尿液理化与微观成分，筛查泌尿系统疾病（感染、结石、肾病）、糖尿病、肝胆疾病等。留取方式直接影响结果，**正确留尿很重要**。

### 尿常规三大块
1. 理化：颜色、比重、酸碱度
2. 化学成分：蛋白、糖、潜血、白细胞酯酶、胆红素等
3. 镜检：红细胞、白细胞、管型、结晶

## 常见指标参考与意义

| 指标 | 正常参考 | 异常提示 |
|------|---------|---------|
| 颜色 | 淡黄/清亮 | 红/茶色见下；浑浊见感染 |
| 比重 | 1.003-1.030 | 固定低比重提示肾浓缩功能减退 |
| pH | 4.5-8.0 | 过酸/过碱与饮食、疾病有关 |
| 尿蛋白 | 阴性(±) | 阳性见肾病、高血压/糖尿病肾损害 |
| 尿糖 | 阴性 | 阳性见糖尿病、肾性糖尿 |
| 尿潜血/红细胞 | 阴性或极少 | 见结石、感染、肾小球疾病等 |
| 白细胞酯酶/白细胞 | 阴性 | 阳性提示尿路感染 |
| 亚硝酸盐 | 阴性 | 阳性提示细菌感染 |
| 胆红素/尿胆原 | 阴性/± | 肝胆疾病时升高 |

## 常见结果解读

### 尿蛋白阳性（重视）
1. 常见：剧烈运动、发热、紧张、体位性（一过性）
2. 持续阳性：肾小球肾炎、糖尿病/高血压肾损害、肾病综合征
3. **持续蛋白尿须就医完善肾功能、24h尿蛋白定量**
4. 尿微量白蛋白是发现糖尿病早期肾病的重要指标

### 尿糖阳性
1. 最常见：糖尿病血糖升高
2. 妊娠期生理性尿糖可阳性
3. 肾性糖尿：血糖正常而尿糖阳性（肾小管功能障碍）
4. 结合血糖判断，勿单凭尿糖

### 潜血/红细胞阳性
1. 常见：尿路感染、结石、剧烈运动、女性月经污染
2. 持续/肉眼血尿：肿瘤、肾病、外伤需排查
3. **肉眼血尿（尿色鲜红/茶色）须立即就医**

### 白细胞阳性（提示尿路感染）
1. 常伴尿频、尿急、尿痛
2. 女性更常见，注意需在医生指导下规范抗生素治疗

## 正确留尿要点（结果准确关键）
1. 尽量晨起第一次中段尿，收集"中段"最准
2. 使用清洁容器，采后尽快送检（1小时内查最准）
3. **女性避开月经期**，留尿前清洁外阴，防污染
4. 留尿前避免剧烈运动、大量饮水稀释
5. 需遵医嘱停用可能影响结果的药物

## 需及时就医的信号
1. 肉眼血尿、持续镜下血尿伴血块
2. 持续蛋白尿，或伴泡沫尿、眼睑/下肢水肿（警惕肾病）
3. 尿痛、尿频、尿急、发热（提示感染）
4. 尿糖反复阳性且伴多饮多尿多食消瘦
