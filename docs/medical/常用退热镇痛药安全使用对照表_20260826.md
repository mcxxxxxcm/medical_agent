## 常见退热镇痛药概述

### 家庭最常用两类
1. 对乙酰氨基酚（扑热息痛）：市售如泰诺林、必理通
2. 布洛芬（非甾体抗炎药NSAID）：市售如芬必得、美林（儿童）
两者均用于退热和轻中度疼痛，但机制、适用人群、注意事项不同，**不可盲目混用或同时服用**。

## 药物对照表

| 药名 | 对乙酰氨基酚 | 布洛芬 |
|------|-------------|--------|
| 剂型 | 片剂、混悬液、栓剂 | 片剂、缓释胶囊、混悬液 |
| 退热起效 | 较快 | 稍慢但持久 |
| 主要代谢 | 肝脏 | 肾脏 |
| 对胃肠道刺激 | 较小 | 较大 |
| 发热痛首选 | 老人、孕早期、肝功能正常者 | 关节痛、肌肉痛、炎症明显者 |
| 成人单次常用量 | 0.5g/次 | 0.3-0.4g/次 |
| 每日常用上限 | ≤2g（特殊情况遵医嘱） | ≤1.2g（分次） |

## 用量与间隔要点
1. 退热药体温≥38.5℃或有明显不适时使用，目的以缓解不适为主
2. 每次服药间隔≥4-6小时
3. 24小时内用药次数不超过4次
4. 体温<38.5℃且精神可时，优先物理降温（多饮水、温水擦浴）

## 关键安全红线（务必遵守）
1. **对乙酰氨基酚过量伤肝**：成人大剂量可致急性肝损伤，切忌与含相同成分的复方感冒药同服（易叠加过量）
2. **布洛芬伤胃肠**：有胃溃疡、消化道出血史者慎用，建议餐后服用
3. **两种药不要同时吃**：同类作用叠加、副反应风险增加；确需交替时须遵医嘱或严格错开时间
4. **儿童严格按体重给药**：用儿童专用剂型（混悬液），勿用成人片剂自行掰分

## 特殊人群注意
| 人群 | 注意 |
|------|------|
| 孕妇 | 孕早期尽量避免布洛芬；对乙酰氨基酚在医生指导下使用 |
| 肝功能不全者 | 慎用对乙酰氨基酚 |
| 肾功能不全者 | 慎用布洛芬 |
| 哮喘患者 | 部分对阿司匹林/NSAID过敏，布洛芬慎用 |
| 3月以下婴儿 | 发热必须就医，勿自行喂药 |

## 需立即就医的危险信号
1. 发热伴抽搐、意识不清、呼吸急促
2. 用药后出现呕吐、上腹剧痛
3. 皮疹、眼睑/口唇肿胀（警惕过敏/药疹）
4. 发热超过3天不退，或退而复升
5. 儿童精神萎靡、烦躁、拒食、前囟隆起

## 常见误区
1. 体温一定要降到正常 x 以缓解不适为目标即可
2. 好几种感冒药一起吃 x 成分重复易过量
3. 成人药减半给孩子吃 x 剂量不精确，有风险
4. 发热就马上打针 x 多数病毒性发热可居家退热
