# 特殊人群用药安全指南

## 文档说明
- 版本：v1
- 更新日期：2026-08-26
- 目标读者：儿童家长、孕妇/哺乳期女性、老年人及其照护者
- 资料来源：综合药理学与特殊人群用药规范，供家庭用药参考

## 特殊人群用药概述
儿童、孕妇/哺乳期、老年人因生理特点不同，药物在体内的吸收、分布、代谢、排泄差异显著，用药剂量、禁忌、风险与普通成人不同。**用药错误对这类人群危害更大**，需格外谨慎。

## 儿童用药安全

### 基本原则
1. 儿童不是"缩小版成人"，剂量须按体重或体表面积计算
2. 优先儿童专用剂型、味觉适宜、剂量准确的制剂
3. 3月以下婴儿任何用药、发热均需就医
4. 避免私自掰开成人片剂减量给药（剂量不均匀）

### 常见安全注意
| 事项 | 说明 |
|------|------|
| 退热 | 优先对乙酰氨基酚或布洛芬，按体重给药，勿超量 |
| 抗生素 | 严格遵医嘱足疗程，勿自停 |
| 镇咳药 | 2岁以下不建议自行使用中枢镇咳药 |
| 阿司匹林 | 儿童发热/病毒感染时禁用（可能诱发瑞氏综合征） |
| 中药/保健品 | 须咨询专业人员并按说明书，勿超量 |

### 用药五查五对
用药前核对：药品名、剂量、时间、途径、是否对症，儿童尤其须反复核对。

## 孕妇/哺乳期用药安全

### 基本认识
1. 孕期药物可能影响胎儿发育，尤其孕早期（前3个月）
2. 部分药物可经乳汁进入婴儿体内
3. 关键原则：**不自行用药，也不因怕风险而拒绝必需治疗**

### 分级与注意
| 类别 | 说明 | 示例 |
|------|------|------|
| 需在医生指导下 | 大多数用药须遵医嘱权衡利弊 | 降压、抗感染、胰岛素 |
| 避免使用 | 有明显致畸风险 | 异维A酸、部分降压药(ACEI/ARB) |
| 哺乳慎用 | 可能经乳汁影响婴儿 | 部分镇静药、某些抗生素 |

### 孕产期用药备忘
1. 孕前如有慢病（高血压、糖尿病、癫痫、甲状腺病）先与医生优化方案
2. 孕期发热、感染、疼痛须在产科/专科医生指导下用药
3. 哺乳期服药前咨询哺乳用药风险，多数常用药可交代医生权衡
4. 保留就诊时用药记录，复诊时展示

## 老年人用药安全

### 老年人用药特点与风险
1. 肝肾功能随年龄减退，药物排泄变慢，易蓄积中毒
2. 常多病共存、多药共用，相互作用与不良反应风险高
3. 对镇静、降压、降糖药敏感，易头晕、跌倒、低血压、低血糖

### 核心管理要点
1. **用药清单化**：记录全部药物，复诊/药房取药时出示，防重复开药
2. **从低剂量开始**：新药起始剂量通常低于年轻人，缓慢调整
3. **"能少则少"**：定期请医生精简药物（避免"处方瀑布"）
4. **警惕"隐形药"**：含伪麻黄碱感冒药、某些中成药成分会干扰血压血糖
5. **高跌倒风险药物**：镇静催眠、利尿、晕车药等，起床/起身要缓慢

### 常见需关注的老年药物
| 类别 | 风险 | 对策 |
|------|------|------|
| 长效镇静药 | 跌倒、认知影响 | 缩短疗程，必要时减量 |
| 抗胆碱药 | 口干、便秘、尿潴留 | 慎用，替代方案 |
| 强利尿剂 | 低钾、低血压、跌倒 | 监测电解质、血压 |

## 共同风险信号（需立即就医）
1. 用药后晕厥、跌倒、意识模糊
2. 明显乏力、食欲差、尿量减少
3. 剧烈头痛、心悸、呼吸困难
4. 皮肤黄染、出血倾向、肌肉酸痛伴深色尿
