## 过敏性休克概述

### 什么是过敏性休克
过敏性休克是接触过敏原后，机体发生迅速、剧烈的全身性过敏反应，导致血压骤降、气道水肿、多器官功能衰竭，**可在数分钟内危及生命**。最常见诱因包括药物、食物、昆虫蜇咬、部分疫苗等。

### 常见诱因
1. 药物：青霉素等抗生素、造影剂、阿司匹林/NSAID
2. 食物：花生、坚果、海鲜、蛋、牛奶、小麦
3. 昆虫：蜜蜂、黄蜂蜇刺
4. 乳胶、部分疫苗

## 过敏性休克快速识别
过敏反应进展迅速（数分钟至2小时内），紧记"累及多系统"：

### 表现清单
1. **皮肤**：全身荨麻疹、瘙痒、面部唇舌肿胀
2. **呼吸道**：喉头水肿、喘鸣、呼吸困难、声音嘶哑
3. **心血管**：血压骤降、头晕、晕厥、面色苍白、心悸
4. **消化**：恶心呕吐、腹痛、腹泻
5. **神经**：意识模糊、呼吸骤停

### 危险信号（提示休克/气道狭窄，须立即处置）
1. 呼吸困难、喉头肿胀感、喘鸣
2. 头晕、眼前发黑、晕厥
3. 声音嘶哑、吞咽困难
4. 皮肤湿冷、脉搏细弱

## 家庭急救正确做法

### 正确步骤
1. **立即呼救拨打120/急救电话**
2. **停止接触并移除过敏原**（停用可疑药物、脱离过敏环境、拔除蜂刺）
3. **保持平卧，抬高双下肢**（改善回心血量，低血压时勿站立）
4. **有肾上腺素自动注射笔者立刻遵说明注射大腿外侧**（过敏性休克一线药物，勿等待）
5. 有呼吸困难者保持半坐位，解开衣领保持气道通畅
6. 若意识丧失、呼吸心跳骤停，立即CPR并取AED
7. 密切观察直至专业人员接诊

### 关键：肾上腺素是首选救命药
1. 过敏性休克**首选肌注肾上腺素**（大腿外侧），非口服抗过敏药
2. 有过敏史者常备肾上腺素自动注射笔，家人需学会使用方法
3. 抗组胺药、糖皮质激素仅作辅助，不能替代肾上腺素抢救

### 禁忌（请勿做）
1. 切勿让患者站立或行走（可加重休克致倒地）
2. 切勿喂水、喂药（吞咽困难或昏迷时更危险）
3. 切勿拖延拨打120、仅靠刮痧/喝药"压一压"
4. 轻度反应缓解后仍需就医观察（迟发性双相反应可能）

## 预防要点
1. 明确记录并告知医护过敏史（过敏原、过敏反应类型）
2. 避免致敏食物/药物，外食、用药前确认成分
3. 高危者随身携带急救卡和肾上腺素笔
4. 养蜂区、户外活动穿好防护，避开蜂巢
