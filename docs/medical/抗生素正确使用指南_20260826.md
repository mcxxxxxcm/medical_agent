## 抗生素概述

### 什么是抗生素
抗生素（抗菌药物）是用于治疗细菌感染的药物，对病毒（如普通感冒、流感、多数咽痛）**无效**。常见类别包括青霉素类、头孢菌素类、大环内酯类、喹诺酮类等。

### 抗生素≠消炎药
1. 多数"炎症"（如普通咽炎、非感染性关节炎）并非细菌感染，抗生素无效
2. 阿司匹林、布洛芬等是"消炎镇痛药"，与抗生素作用完全不同
3. 发烧、喉咙痛、流涕最常见原因是病毒，吃抗生素无益且有害

## 抗生素使用核心原则

### 1. 需医师处方才能使用
1. 凭医生处方使用，勿自行购买、勿用他人剩余药
2. 医生判断为细菌感染（如化脓性扁桃体炎、细菌性肺炎、泌尿道感染）才用

### 2. 足疗程、足剂量
1. 严格按医生规定的剂量和疗程服用，不得擅自减量或提前停药
2. 症状好转不等于感染清除，提前停药易致复发和耐药
3. 按时服用，漏服勿一次补双倍

### 3. 不随意换药、不混用
1. 效果不佳找医生评估，勿自行增加剂量或联合其他抗菌药
2. 不同厂家、不同类药物不可随意混用

## 常见抗生素类别与注意
| 类别 | 代表药 | 常见注意 |
|------|--------|---------|
| 青霉素类 | 阿莫西林 | 青霉素过敏者禁用，需皮试/询问过敏史 |
| 头孢菌素类 | 头孢克肟、头孢拉定 | 过敏者慎用；头孢类避免饮酒 |
| 大环内酯类 | 阿奇霉素、罗红霉素 | 胃肠道不适常见 |
| 喹诺酮类 | 左氧氟沙星 | 18岁以下、孕妇慎用，避免日光暴晒 |
| 四环素类 | 多西环素 | 儿童牙齿发育期慎用 |

### 服用抗生素期间禁忌
1. 服用头孢类、甲硝唑期间及停药后1周内**禁忌饮酒**（可能诱发双硫仑样反应，严重可致命）
2. 与某些药物（如华法林、部分降糖药）存在相互作用，合用时咨询医生

## 耐药性危害（认识抗生素滥用后果）
1. 细菌逐渐对常用药"刀枪不入"，导致治疗失败
2. 未来感染更难治，治疗周期延长、费用上升、后果更严重
3. 耐药菌（如超级细菌）感染死亡率高，是重大公共卫生威胁

## 常见误区纠正
1. 感冒咳嗽就吃"消炎药" x 多数为病毒，吃抗生素无效
2. 症状好点就停药 x 疗程不足致复发、耐药
3. 越贵越新的抗生素越好 x 针对敏感菌才是关键
4. 剩药留着下次吃，或分享给家人 x 药不对症且延误治疗

## 正确用药指引
1. 遵循"能口服不肌注、能肌注不输液"原则
2. 严格遵医嘱；用药中出现皮疹、过敏、严重腹泻及时就医
3. 儿童、孕妇、老人、肾功能不全者须在医生指导下选择药物和剂量
4. 出现抗生素相关性腹泻（尤其是严重、治疗银坑无效者）就医评估

## 需立即就医的危险信号
1. 服药后出现皮疹、瘙痒、呼吸困难（警惕过敏/过敏性休克）
2. 严重腹泻（警惕艰难梭菌感染）
3. 大剂量误服、儿童误服抗生素
4. 头孢/甲硝唑期间饮酒后出现面红、心悸、胸闷（双硫仑反应）
