## 急性心肌梗死概述

### 什么是心梗
急性心肌梗死是冠状动脉急性闭塞、心肌缺血坏死。救治强调"时间就是心肌"，早期再灌注（急诊介入PCI）能最大程度挽救心肌、降低死亡。**就诊越早，预后越好。**

## 典型症状识别

### 心梗典型表现
1. **胸骨后或心前区压榨样、紧缩感剧痛**
2. 疼痛向左臂、肩、背、颈部、下颌放射
3. 持续**>20分钟**，休息或含服硝酸甘油不缓解
4. 常伴大汗淋漓、面色苍白、恶心呕吐、濒死感

### 不典型表现（易被忽视，尤其高危人群）
1. 老年女性：以气短、乏力、背部痛、上腹不适为主
2. 糖尿病患者：因神经病变，可表现为"无症状"或仅有乏力（无痛性心梗）
3. 仅表现为上腹痛、胃部不适（易误当胃病）
4. 突发的极度疲劳、晕厥、心慌

### 需立即急救的危险信号
1. 持续胸痛>15分钟，含硝酸甘油无缓解
2. 伴大汗、濒死感、意识模糊
3. 晕厥、血压下降、脉搏细弱
4. 心梗合并心力衰竭：端坐呼吸、粉红色泡沫痰

## 家庭急救正确做法

### 正确步骤
1. **立即拨打120/急救电话**，告知疑似心梗
2. **让患者立即安静平卧/半坐**，切勿自行走动、用力
3. 有条件且无禁忌（血压不低、无过敏）时，遵医嘱舌下含服硝酸甘油1片
4. 有阿司匹林者，在医生电话指导下权衡（确诊为心梗且无禁忌可嚼服300mg）——**首要是求救**
5. 保持呼吸道通畅，解开领口
6. 若意识丧失、呼吸心跳骤停，立即实施心肺复苏（CPR），AVD呼叫除颤

### 禁忌（请勿做）
1. 切勿让患者自己走动、上楼、开车去医院
2. 切勿反复灌水、催促活动
3. 切勿自行剧烈按压胸口、乱喂药
4. 切勿等待症状自行缓解——多数心梗不会自行好转

## 心肺复苏（CPR）要点（若患者无反应、无呼吸）
1. 立即呼救并拨打120，取自动体外除颤器（AED）
2. 胸外按压：两乳头连线中点，深度5-6cm，频率100-120次/分
3. 让患者平卧硬板上，持续按压至专业人员接手
4. 有AED则按语音提示电击除颤
5. 仅接受过培训者操作；未经培训者也应尽力呼叫并维持按压

## 心梗风险人群与预防
1. 高血压、糖尿病、高血脂、吸烟、肥胖、老年人
2. 既往有冠心病、心绞痛、支架/搭桥史者
3. 控制三高、戒烟、管理体重、规律运动、规律服药（他汀、抗血小板药勿自行停药）

## 随访管理（心梗后）
1. 出院后严格遵医嘱服药（双抗、他汀、β受体阻滞剂等）不可停
2. 定期复查心电图、心脏超声、血脂
3. 心脏康复：遵医嘱逐步恢复体力活动
4. 出现再发胸痛、气短及时就医
