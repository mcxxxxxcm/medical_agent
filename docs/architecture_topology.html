三、核心处理管线
文字问诊路径
1
症状解析 + 口语化同义词替换
35+条口语→医学术语映射，如"拉肚子→腹泻"
↓
2
查询重写 + HyDE
生成FINAL完整问句 + SEARCH关键词 + HyDE假想答案
↓
3
混合检索（Dense + Sparse）
向量检索(K=5~8) + BM25稀疏检索 → RRF融合 → Reranker精排
↓
4
三层拒答 + 文档评分
时效过滤 → 版本去重 → 置信度评分(4维×时效×权威) → 分级路由
↓
5
RAG生成 + 引用标注
基于检索文档生成答案，关键事实标注[来源:文档名]
图片问诊路径
V1
VLM结构化提取（JSON输出）
glm-4v-plus识别图片类型，输出客观描述+可能方向+置信度
↓
V2
OCR数值校准（仅数据类图片）
报告/处方/药盒 → PaddleOCR精确提取数值 → 注入VLM Prompt
↓
V3
安全性校验
不确定内容追问 / 低置信度拦截 / 非医疗图片引导
↓
V4
RAG检索生成
VLM提取信息构造查询 → 走文字路径Step3~5 → 知识库佐证回答
四、安全护栏 & 上下文管理
三层拒答机制
R1
检索层：硬门槛 + 软过滤
时效过滤(过期剔除) + 权威加权 + 版本去重 + 置信度评分
↓
R2
生成层：分级拒答
完全无匹配→拒答引导 / 信息不完整→部分回答+声明 / 多源冲突→展示分歧
↓
R3
输出层：安全审查
规则引擎(0ms) + LLM深度审查(高风险触发) → pass/revise/block

↓
C3
