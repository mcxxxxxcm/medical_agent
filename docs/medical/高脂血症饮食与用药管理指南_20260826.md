## 高脂血症概述

### 什么是高脂血症
高脂血症（血脂异常）是指血脂指标超出正常范围，主要包括总胆固醇（TC）、甘油三酯（TG）、低密度脂蛋白胆固醇（LDL-C）升高，以及高密度脂蛋白胆固醇（HDL-C）过低。LDL-C是"坏胆固醇"，是动脉粥样硬化和心脑血管事件的主要危险因素。

### 常见血脂指标
| 指标 | 含义 | 一般参考水平 |
|------|------|-------------|
| 总胆固醇(TC) | 血中胆固醇总量 | <5.2mmol/L |
| 甘油三酯(TG) | 血中脂肪含量 | <1.7mmol/L |
| LDL-C | "坏胆固醇"，致动脉硬化主因 | <3.4mmol/L |
| HDL-C | "好胆固醇"，保护血管 | ≥1.0mmol/L |

### 类型
1. 高胆固醇血症：以LDL-C升高为主（最常见，危害大）
2. 高甘油三酯血症：以TG升高为主，与饮酒、高脂饮食、肥胖相关
3. 混合型高脂血症：TC与TG均升高
4. 低HDL-C血症：高密度脂蛋白偏低

## 病因与危险因素
1. 遗传因素（家族性高胆固醇血症）
2. 高脂、高糖、高热量饮食
3. 肥胖、缺乏运动
4. 吸烟、饮酒
5. 糖尿病、甲状腺功能减退、肾病等继发疾病
6. 某些药物（如部分降压药、糖皮质激素）影响

## 高脂血症的表现
多数血脂异常无明显症状，常在体检中发现。严重升高时可表现为：
1. 眼睑黄色瘤、皮肤黄色瘤（胆固醇沉积）
2. 角膜老年环
3. 反复急性腹痛（TG极高时警惕急性胰腺炎）

### 需警惕的危险信号
1. TG>5.6mmol/L：急性胰腺炎风险显著升高，需立即就医
2. 有冠心病、中风病史者LDL-C需强化控制
3. 伴高血压、糖尿病、吸烟等多种危险因素者

## 生活方式管理（首要基础治疗）

### 饮食管理
1. 控制总热量，减少饱和脂肪（肥肉、猪油、黄油）和反式脂肪（油炸、糕点）
2. 增加膳食纤维（全谷、豆类、蔬菜水果）
3. 适量鱼类（富含Omega-3，有益TG降低）
4. 严格限制精制糖和含糖饮料
5. 高TG血症者严格限酒或戒酒
6. 多不饱和脂肪酸（植物油）适量，坚果适量（每日一小把）

### 运动与减重
1. 每周至少150分钟中等强度有氧运动
2. 超重/肥胖者减重5%-10%（显著改善血脂）
3. 力量训练每周2次辅助代谢
4. 戒烟

## 药物治疗

### 常用降脂药分类
| 药物类别 | 代表药 | 作用/注意事项 |
|---------|--------|------------|
| 他汀类 | 阿托伐他汀、瑞舒伐他汀 | 降LDL-C一线用药，注意肌痛、肝功能异常 |
| 胆固醇吸收抑制剂 | 依折麦布 | 减少胆固醇吸收，常与他汀联用 |
| PCSK9抑制剂 | 阿利西尤单抗 | 强效降LDL-C，注射制剂 |
| 贝特类 | 非诺贝特 | 主要降TG |
| 高纯度鱼油制剂 | EPA乙酯 | 辅助降TG |

### 用药注意
1. 他汀类常见副作用：肌肉酸痛、乏力、肝功能异常、血糖升高
2. 出现不明原因肌肉酸痛、深色尿、明显乏力及时就医
3. 服用他汀期间定期复查肝功、肌酶
4. 已测血脂达标仍需维持治疗，勿自行停药（否则斑块风险回升）

### 用药原则
1. 降脂药多需长期服用，目标是稳定动脉粥样硬化斑块
2. 服药时间：他汀类通常睡前服用
3. 与柚子（西柚）同服会影响药物代谢，需注意
4. 任何用药调整须遵医嘱

## 并发症与危险信号
1. 动脉粥样硬化：冠心病、脑卒中、外周血管病
2. 急性胰腺炎：TG极高时，突发上腹剧痛、恶心呕吐
3. 用药期间肌肉损伤（横纹肌溶解）、肝损伤

### 需立即就医的紧急情况
1. TG≥5.6mmol/L且有腹痛
2. 突发胸痛、单侧肢体无力、言语不清
3. 服用他汀后出现深色尿、明显肌无力

## 就医与随访
1. 治疗初期每1-3个月复查血脂、肝功、肌酶
2. 稳定后每3-6个月复查
3. 已确诊冠心病/糖尿病/肾病的"极高危"人群LDL-C目标更严格，遵医嘱
4. 联合生活方式管理与药物治疗，双重干预
